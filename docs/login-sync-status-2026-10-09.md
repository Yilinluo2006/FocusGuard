# 登录与同步状态提示

统一区分网络断开、服务器不可达、响应超时、服务异常、账号权限不足、登录过期、同步关闭和未登录。NetworkEnvironment 只用于错误分类，不在请求前拦截网络访问；开发版 127.0.0.1 USB 后端不依赖互联网，因此无公网连接时本地连接失败仍标为服务器不可达。

受保护请求只有确认 HTTP401 且请求凭证仍匹配当前会话时才失效。移除令牌，保留当前账号标识与显示资料并保存 session_expired；显式退出仍清除全部会话，新登录清除过期标记。保存、失效及资料更新使用同一进程锁，旧401不能清掉更新后的登录。IOException、503、403及超时均不清除会话。公开登录请求401表示授权/密码验证失败，不会失效已有账号。

同步错误使用带HTTP状态的异常，避免401/503全部被归成等待联网。服务端已确认完成整轮设置、用时、守约同步后才更新 lastSuccessSync；设置冲突、失败、关闭同步均保留上一成功时间。时间与当前账号和服务器匹配，旧账号时间不会显示给新账号。旧lastSync仅在无冲突的已有安装中读取兼容。

设备同步页新增最后成功同步时间，并在真正未登录/过期时提供登录入口。关闭同步时立即同步不可用，连接失败时登录保留且可重试。设置页分别显示云端备份状态、设备同步状态和最后成功同步时间；账号页明确显示登录过期而非笼统未登录。微信网络失败按钮显示重试连接，避免服务器问题提示用户反复重新登录。

验证：5项纯Java错误分类测试、7项独立Android会话与同步提示测试、6项微信客户端回归全部通过，共18项。测试以独立.setupprobe包和假的响应/异常验证，不更改用户账号或系统网络。真实手机现有令牌能够访问后端 profile（HTTP200），更新前后登录指纹、账号及任务/额度/计划/历史/同步开关一致。新版已安装手机470e575c，临时测试包已卸载。
