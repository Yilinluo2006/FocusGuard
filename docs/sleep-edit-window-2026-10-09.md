# 睡前管控修改时段与防改时钟（2026-10-09）

沿用本机应用额度现有的放宽修改时段，当前为每日 07:00–08:00（开始包含、结束不包含）。其他时间可加强计划；本次不更改用户原计划、额度、监控频率或系统时间。

开启原本关闭的计划、增加星期、延长时长、移除可用应用属于加强。关闭已开启计划、缩短时长、去掉星期、增加可用应用，或移动开始时间使原受控时段丢失，属于放宽。提前开始并延长到仍覆盖原时段可视为加强。跨午夜按开始日和整个星期的覆盖计算；有未来时区偏移变化的地区，移时保守要求在放宽窗口内操作，避免夏令时回拨使名义覆盖和实际结束时间不一致。

睡眠进行中仍禁止改计划和可用应用；已开始的专注也保留原页面编辑限制。每次睡眠的五次临时授权、时长和到期管控不改变。

UI 在保存前及确认后检查，provider 在实际提交时再次检查完整候选计划，包含 remove/clear 和默认值；白名单、同步及备份补缺字段同样校验。使用现有 ProtectionClock / RestrictionStore，不按系统墙钟直接开放窗口：系统时间/日期/时区偏移、未核验重启都不开放放宽；同次开机已校验后的正常离线单调时间继续有效。

同步请求的比较、应用或暂存及回放由 provider 同一写锁串行处理。过期快照不会复活被用户取消的 pendingSleep；用户本地加强或备份恢复有效计划前先成功取消旧暂存。放宽远端计划在窗口外保留暂存、继续本地计划，其他配置可同步；可用时再尝试应用。

验证记录与结果见 build/diagnostics/sleep-edit-window/。最终已完成正式覆盖安装与原数据核对。
