# 默认管控规则

应用只提供默认的严格执行行为，不增加宽松模式开关。

- 本机应用额度与本机共用的五次临时使用耗尽后，继续拦截至下一个 04:00。
- 移除旧版“中断坚持并解除当天限制”的入口和底层无限放行；旧 release 记录不再生效。
- 第五次申请仍完整提供两分钟，到时重新拦截；第六次申请在存储层拒绝。
- 已耗尽应用的额度保留到下一个 04:00，设置同步中的增加额度或移除应用不能立即解除这一限制。
- 睡前计划的五次临时使用到时后继续管控，返回桌面仍显示管控界面；桌面即使曾被列入白名单也不能豁免。
- 睡眠期间拒绝直接结束、修改计划、改白名单及旧版 dismissed 放行，跨 04:00 的同一睡眠计划不会补发次数。
- 电话、系统授权管理和既有可用应用仍按既有规则处理；普通应用不接管系统的卸载、停用权限。

应用额度设置弹窗、首次启用确认、睡前计划保存确认及规则说明均告知上述限制。应用限制到 04:00 恢复，睡眠限制到该计划原定结束时间恢复。

应用额度仍每台设备独立。2026-10-08 修复后，睡眠临时使用也改为每台设备每轮各五次，离线可用；睡前计划配置继续同步。

验证包括纯 Java 的过期、跨日、五次上限和桌面策略，以及独立 Android 测试包的第五次过期、第六次拒绝、旧放行失效、设置覆盖和活动睡眠不可修改。真实应用的数据不用于构造测试。

## 验证结果

- 20 项 JUnit 规则测试通过。Gradle 测试进程因本机 `GradleWorkerMain` 类路径故障无法启动，使用同一批已编译测试直接运行 JUnitCore，通过全部断言。
- 手机上的独立测试包通过 10 项 Android 测试，覆盖应用第五次授权到时、第六次拒绝、旧无限放行失效、当日锁定保留、旧睡眠退出记录失效及计划修改拒绝。
- 正式 debug APK 构建成功，已覆盖安装到手机 470e575c；任务、睡前计划、限制、历史及同步开关通过更新前后比对。
- 安装后无障碍服务已绑定、保护服务运行、没有无障碍崩溃服务；实机计划页面可见严格规则提示。
- 本次仅安装手机，未更新平板。手机的整夜后台持续执行仍需正常使用观察。
