# 睡眠时段自动深色

睡眠计划生效期间，临时将本应用主题设为深色。覆盖睡眠遮挡、工具箱与允许使用时本应用各页面；五次全局临时使用不会取消深色。原外观文件保留，睡眠结束后按跟随系统/浅色/深色原偏好恢复；睡眠期间手动浅色切换被提示阻止，不写入原偏好。

Application 启动先从磁盘计划作初始主题判定，避免初始化时调用配置 provider。初始化完成后和 Activity 前台每秒核对 writer 进程的真实计划；离开所有 Activity 后取消此检查。既有睡眠控制器刷新时同步主题，并通过本包广播通知另一进程。规则使用 ProtectionClock 与 FocusSchedule 的星期选择、跨午夜和精确结束时间；不改系统时间、系统全局深色设置或睡前计划。

3项纯Java时间与偏好规则测试、2项独立Android实际 AppCompatDelegate/遮挡上下文/临时使用测试通过，涵盖睡眠开始深色、临时放行深色、结束恢复浅色与原偏好未被替换。独立测试包卸载，新版已安装手机470e575c。任务、额度、睡前计划、历史和同步设置通过更新前后核对。外观由安装前深色变为安装后浅色，用户明确确认这是自己手动切换；保留其最新浅色选择，不恢复旧深色值。

未修改用户真实计划来模拟夜间。真实夜间视觉表现仍可在今晚睡眠时段检查。平板此轮未连接，尚未更新。
