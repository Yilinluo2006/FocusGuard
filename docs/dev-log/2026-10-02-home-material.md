# 首页 Material 3 样板

保留现有 Java + XML 技术与 Material 1.10.0 依赖，先调整首页和共用底部导航。
深色 #212121 纯色背景、浅色背景和现有金色强调色沿用已有设置。

## 样式

- 首页采用 20dp 横向边距、32sp 标题，显示当前日期。
- 新建专注使用平面 Material 按钮，圆角 16dp、最小高度 56dp，内容随字体扩展。
- 任务卡片圆角 20dp，无描边、无阴影；突出分钟/轮数，管理入口保留 48dp 点击范围。
- 空列表显示真实空状态；已有任务显示实际数量，不添加示例数据。
- 任务表单改用 Material 弹窗，单选项纵向排列，内容可滚动。
- 底部导航使用同一线条风格图标、24dp 图标尺寸、80dp 高度和 12sp 标签。
- 颜色、按钮和尺寸集中在 home_styles.xml，作为后续页面样式的参考。

任务创建、仅保存、保存并开始、编辑、删除及计时启动继续使用原有存储和流程。
专注/睡眠互斥、每日额度、04:00 重置、白名单及保护服务逻辑均未调整。

## 卡片紧凑与渐变调整

根据用户反馈，任务卡片从名称、模式、时长三行改为两行：名称和管理入口一行，
模式/时长和开始提示一行。缩小上下留白和装饰图标，管理按钮仍保留 48dp 点击范围。
卡片高度随内容增长，长名称和大字体仍可扩展。

倒计时采用蓝色渐变、正计时采用青绿色渐变、番茄钟采用红色渐变。
浅色模式使用对应的浅色渐变；深色模式使用较深且更明显的颜色与浅色文字。
背景资源和颜色独立于其他页面，空状态卡片保持原样。
