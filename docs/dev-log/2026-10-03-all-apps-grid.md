# 全部应用紧凑网格

- “全部应用”使用独立的紧凑卡片布局，普通手机两列，大屏最多三列；大字体时根据可用宽度减少列数。
- 保留原有卡片背景、圆角、图标、限制开关、用量和额度编辑入口；名称最多两行，进度条与额度耗尽颜色继续显示。
- “已限制”继续使用原有单列布局和字号。
- 两种布局使用不同 RecyclerView viewType，防止切换时复用错误的卡片样式；按列分配 8dp 横向间距。
- 搜索、限制变更确认、额度保存、应用排序与刷新沿用原有入口。

## 验证

- 离线 assembleDebug 成功。
- 安装前确认普通专注、番茄钟和睡前管控均未运行。
- APK SHA-256 校验通过后覆盖安装成功，保留用户数据。
- 实机进入“已限制”时仍为单列；切换“全部应用”的截图确认左右两列紧凑卡片。
- 检查期间出现既有“保护已暂停”提示，遮挡部分网格；未修改系统权限，未操作应用限制开关和额度。未声称验证限制保存、三列大屏或其他机型。
