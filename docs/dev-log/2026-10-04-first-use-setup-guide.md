# 首次使用引导与必要设置入口（2026-10-04）

## 实现

- 首次进入主页面时，若使用记录、无障碍、浮窗授权尚未齐全，打开「开启专注保护」清单。
- 用户可选择「稍后」，后续不反复弹出首次引导；设置页保留入口。
- 已有完整授权的安装不会因升级强制打开引导。
- 设置页最上方新增「必要设置」卡片、完成数和金色立体按钮。
- 四项清单为使用记录、无障碍服务、浮窗显示、后台保护，底部固定按钮跳转到下一未完成项。
- 后台运行及通知提醒列为建议项，不阻塞完成设置。
- 返回页面或页面停留期间重新读取权限及服务心跳，不用本地「已点击」标记冒充已授权。
- 无障碍授权开关与真实服务连接分开检查。开关开着但连接失效时明确显示「已断开」，引导关闭再开启。
- 系统设置页面不可用时退回通用设置或应用详情页。
