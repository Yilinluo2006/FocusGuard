> 状态：用户要求恢复上一版，本次首页视觉调整已撤回。恢复了三种渐变、原字号、20dp 圆角和紧凑布局，保留其他已完成的功能。恢复版离线打包成功，检查没有活动专注或睡前管控后已覆盖安装；以下内容留作此次尝试的记录，不代表当前样式。

## 设计审视

首页的主要任务是让用户选择一个专注任务并开始。原来的三种高饱和渐变让同等重要的任务呈现不同的视觉重量，标题和数字也同时抢占注意力。

- 中等：三种专注模式以红、蓝、绿大面积区分，与统一品牌色竞争。改为同一种中性表面，模式由文字识别。
- 中等：页面标题、任务名称、模式数字均强烈强调。统一五级字号，并降低次要数据的强调倍率。
- 保留：单列任务、明确的任务模式文字、48dp 管理入口、整卡开始、立体“新建专注”按钮、现有浅色和深色选择。

本次使用 apple-design 的通用基础指导，落实到 Android 的 TextView、MaterialCardView 和 sp/dp；不把 iOS 专属导航或字体资源引入 Android。

参考依据：

- `branding.md › Best practices`：“Apply your app’s accent color judiciously.” 金色集中用于创建任务和实际状态。
- `typography.md › Conveying hierarchy`：通过字号、字重和颜色建立层级，减少字体混用。
- `layout.md › Visual hierarchy`：对齐和分组帮助扫描，主要任务位于前方。
- `accessibility.md › Vision`：不单靠颜色传达含义，校验文字对比度，支持字号缩放。
- `buttons.md › Best practices`：保留按压反馈与足够的点击区域。
- `dark-mode.md › Dark Mode colors`：通过深浅不同的表面形成层次，并分别检查两种外观。
- 已查阅 `collections.md`、`designing-for-ios.md` 及 `references/cross-platform.md`，采用熟悉的单列内容结构与 Android 平台交互。

## 字体与间距

| 内容 | 大小 | 字重 |
| --- | --- | --- |
| 今日专注 | 28sp | 系统 Medium |
| 专注任务 | 16sp | 系统 Medium |
| 任务名称 | 18sp | 系统 Medium |
| 模式、时长 | 14sp | 系统 Regular，数字仅放大 1.1 倍 |
| 日期、任务数量 | 13sp | 系统 Regular |

- 沿用系统字体，颜色和字号集中在资源样式中。
- 页面左右 20dp；标题上方 8dp、下方 20dp；分组上方 24dp。
- 卡片间距 12dp、圆角 18dp、主要内容左侧内边距 16dp。
- 管理入口保持 48 × 48dp；开始图标置于整卡可点击区域中。
- 卡片高度由文字决定，大字号下任务名称允许更多行；不增加新的动画。

## 结构

紧凑宽度：

```text
日期
今日专注

[       + 新建专注       ]

专注任务              数量
[ 任务名               ⋮ ]
[ 模式 · 时长           ▶ ]

[ 下一项任务             ]
```

常规宽度：仍保持同一阅读顺序和单列结构，任务名称利用额外横向空间，操作保持在卡片右侧。

“奶蛙”的暖黄色与用户指定的立体按钮是本次保留的识别点。卡片用中性色呈现，给任务内容留出视觉优先级；移除模式颜色的大面积装饰。
