# 首页任务卡片：柔和渐变与清晰操作

按用户要求保留三种专注模式的颜色区分，重新调整任务卡片的视觉层级。

- 倒计时雾蓝、正计时玉绿、番茄钟柔珊瑚红；深色模式使用较深的同色渐变，浅色模式使用淡色渐变。
- 20sp 任务名称为主要信息，下方用同色标签标注模式，旁边显示时长或轮数；正计时显示“不限时”。
- 开始提示改为同色圆形按钮外观，继续通过原有整卡点击启动任务；管理入口保持 48dp，改用横向省略号。
- 卡片增加细边框，间距 12dp；大字体或窄屏时，下方模式与时长纵向排列。保留金色立体新建按钮。
- 没有修改任务数据或计时逻辑。

## 验证

- 离线 assembleDebug 成功。
- 两种主题、三种模式的名称、详情、标签（含背景混色）及开始图标的最小对比度均超过 4.5:1。
- 确认手机无活动专注、番茄钟或睡前管控后，校验 APK 并覆盖安装，安装返回 Success。
