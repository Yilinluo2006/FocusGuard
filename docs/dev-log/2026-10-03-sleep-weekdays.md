# 睡前管控按星期重复

- 在重复开关下增加周一至周日的多选按钮，选中用主题金色显示。
- 七天全选时开关名称为“每天重复”，部分选择时为“每周重复”；关闭重复时星期按钮变淡作为提示，但仍可点击调整星期，开启重复并保存后才按所选星期执行。
- 星期与开始时间、时长一并点击“保存计划”后生效；开启重复时至少选择一天。
- 旧计划没有星期设置时默认每天执行；页面重建保留未保存的星期草稿。
- 管控、睡前提醒、管控记录以及普通专注和番茄钟的睡前冲突判断使用同一星期规则。
- 跨午夜按开始当天的星期判断。例如周五 23:30 开始的四小时管控会持续至周六 03:30，周六晚是否执行由周六的选择决定。
- 减少已启用计划的管控天数沿用原有放宽限制确认与连续记录规则。
- 云备份携带星期设置并校验范围，兼容缺少该字段的旧备份；恢复时保留已有本地计划的每天执行规则。
