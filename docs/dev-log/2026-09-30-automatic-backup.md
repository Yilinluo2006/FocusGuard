在现有 Android 本地保护逻辑及 Spring Boot/MySQL 后端上增加账号自动备份和恢复。
保留两仓库所有此前未提交改动，未重置、提交或清空数据库。

## 已完成

- 后端 JWT 认证的各设备快照、用户隔离、摘要校验、幂等重试与版本冲突保护。
- Android 主进程网络工作，设置/已结束记录变化调度上传、离线退避重试和周期核对。
- 账号与备份页面的登录、首次开启、关闭、状态、立即备份及设备选择恢复。
- 恢复按标识补充合并，保留本机已有配置；校验输入和合并规模，拒绝导入运行状态、权限和当前日额度/保护时长。

- 登录凭据与云端设备状态排除在 Android 系统备份/设备迁移之外。
- 后端实际凭据仅写入被 Git 忽略的本机 `.env`；启动脚本和无凭据示例已补齐。
