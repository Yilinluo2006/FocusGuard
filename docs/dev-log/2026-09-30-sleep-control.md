# 睡前应用管控记录

本次沿用已保存的每日开始时间、持续时长、允许应用和每日额度规则。
计划页增加当前管控/保护暂停提示；暂停提示可进入权限恢复页面。
统计页替换睡眠与起床占位，提供月度汇总和所选日期的每次管控详情。

## 记录口径

- 单次记录包含计划开始、计划结束、结束时间，以及计划到时、主动提前解除、计划变更或系统时间变化等结束原因。
- 整次记录按计划开始时刻所属的 04:00 统计日归属，跨日不拆分整次记录。
- 相邻采样间隔不超过 35 秒、同次开机、墙钟与单调时钟差异不超过 2 秒、保护状态一致时才累计对应时长。
- “服务正常”仅表示无障碍启用且心跳正常，不保证每次应用拦截成功，也不表示用户入睡。
- 状态切换、较长休眠/未采样、重启和时钟变化造成的间隔计为待确认；迟到的首次观察不回填保护时间。
- 无障碍关闭与服务异常分别计数。故障不会取消原有计划；恢复后继续执行，主动提前解除仍阻止该计划时段再次启动。
- 完全未被观测的历史夜晚不生成记录；本版前的睡眠计划不回填。
- 记录在结束后纳入统计。查看统计本身只读；主页面状态检查及原有服务心跳负责观察、保存与延迟结算。
