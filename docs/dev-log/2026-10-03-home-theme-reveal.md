# 首页主题切换与圆形扩散

按用户提供的交互参考，在首页右上角加入太阳/月亮按钮。点击直接切换浅色与暗色，新主题从按钮中心以圆形向整页展开，持续 620ms。

## 实现

- HomeFocus 使用 48dp 点击区域与 24dp 图标，按钮提供目标模式的无障碍描述。
- Appearance 复用原有原子文件持久化和跨进程外观通知。设置页仍可选择跟随系统。
- ThemeReveal 在主线程保存旧页面画面，以 ViewModel 跨页面重建传递；新页面布局完成后，通过逐渐扩大的圆形开口显示新主题。
- 动画期间阻止连续触摸；完成、取消、退出页面或尺寸变化时清理覆盖层。页面重建未接续时，3 秒后释放待用画面。
- 截图最多 400 万像素。内存不足、截图失败或系统关闭动画时直接切换主题。
- HomeNavigation 保存并恢复首页、计划及设置页的滚动位置，继续沿用已有页面状态保存。
