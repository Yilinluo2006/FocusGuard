# 应用限制页汇总信息合并

- 将“受限应用今日已用”卡片与“已限制数量 / 临时使用剩余次数”合并为一张两行汇总卡片。
- 第一行左侧为说明，右侧为时长；第二行左侧为限制数量，右侧为临时使用剩余次数。
- 收小数字强调倍率及文字大小，收紧筛选按钮上方间距，给应用列表腾出空间。
- 继续使用原有汇总、选择数量、临时次数更新入口；不改变统计口径、应用额度或临时使用规则。
