# 个人资料与绑定

入口：设置 → 账号与自动备份 → 个人资料与绑定（也可点击头像）。

- 注册只填邮箱和密码，完成邮箱验证后登录；新账号默认名称“小奶娃”、第一张默认头像。
- 个人资料可编辑昵称，选择默认头像与四张备选头像，点击“保存资料”后保存至账号后端。
- 更换绑定邮箱：输入新邮箱和当前密码，向新邮箱发送验证码，填写六位验证码后确认。账号 ID、已有专注记录、备份归属保持不变，之后使用新邮箱登录。
- 昵称可以重复；1–24 个字符，支持表情，不允许空白或换行。旧账号保留原显示名称，可自行修改。
- 后端保存头像资源标识和昵称；新设备登录后获取同一份资料。设备备份不覆盖账号资料。
- 手机号登录 / 注册：短信认证通过后登录，未注册手机号自动创建默认资料。已有邮箱账号应先登录，在个人资料中绑定手机号，继续沿用原账号与备份。
- 首次绑定手机号：登录后只验证新手机号，不要求当前密码。更换已绑定手机号：有密码的账号先验证当前密码；纯手机号账号先验证原手机号，再验证新手机号。纯手机号账号也可验证当前手机号后添加邮箱和邮箱登录密码。
- 短信验证码有效期 5 分钟，每次最多尝试 5 次，不可重复使用；每个手机号 60 秒内最多请求一次、24 小时最多 10 次。
- 微信登录尚未接入。短信服务使用阿里云号码认证的短信认证服务，密钥仅保存在后端环境变量。

API 与验证规则见后端 docs/unified-account.md。所有异步资料响应检查账号 ID 与令牌，避免退出或切换账号后写入旧账号资料。
